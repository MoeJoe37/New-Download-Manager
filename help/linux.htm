NDM on Linux

On Linux, NDM comes as one AppImage file that runs on current distributions without installing. This page covers what differs from Windows.

Running the AppImage

  1. Download NDM-x86_64.AppImage from the release page.
  2. Make it executable: in the file manager, open its properties and tick Allow executing file as program, or run chmod +x NDM-x86_64.AppImage.
  3. Double-click it, or run ./NDM-x86_64.AppImage.

NDM then adds itself to your applications menu, with its icon, so you can start it from there next time. If you move the AppImage, start it once from its new place to update the menu entry.

Systems without FUSE can't mount the AppImage. Start it with ./NDM-x86_64.AppImage --appimage-extract-and-run instead.

The tray icon

KDE Plasma, Xfce, Cinnamon, MATE and Ubuntu's desktop show NDM's tray icon. Stock GNOME shows it once the AppIndicator extension is installed (gnome-shell-extension-appindicator on most distributions).

With a tray icon, closing the window keeps NDM running there, as on Windows. Without one:

  • closing the window while something is downloading or a queue is running minimizes it, and the downloads go on;
  • closing it with nothing running quits NDM;
  • starting NDM again from the menu brings the window back.

Wayland and X11

On Wayland desktops NDM runs through XWayland when it is available, so it can hide its window and keep the drop target on top. Without XWayland it runs on Wayland directly, where hiding to the tray minimizes the window instead.

The browser extension

NDM keeps a copy of its browser extension in ~/.config/NewDownloadManager/extension. Load that folder (see From your browser): it stays in place when the AppImage is updated or moved, so the browser keeps finding it.

  • NDM registers itself with Chrome, Chromium, Edge, Brave, Vivaldi, Opera and Firefox, including Firefox from Snap.
  • Browsers installed as Flatpak, and Chromium from Snap, keep programs outside their sandbox from starting, so they can't hand downloads to NDM.

Where NDM keeps its files

Settings and the download list are in ~/.config/NewDownloadManager (or under $XDG_CONFIG_HOME when it is set). Downloads go to the folders on the Save to page of Options.

System proxy

Use system settings on the Proxy / Socks page reads GNOME's proxy settings (also used by Cinnamon, MATE and Budgie), KDE's, or else the http_proxy, https_proxy, ftp_proxy and no_proxy environment variables. Advanced browser integration writes GNOME's or KDE's settings.

Dial Up / VPN

The Dial Up / VPN page lists NetworkManager's VPN, WireGuard, PPPoE and mobile connections. NDM connects one with nmcli before downloading and can hang it up when a queue is done.

Sounds and shutting down

Sounds play through paplay, pw-play or aplay, whichever is installed. Turn off computer when done shuts down one minute later (shutdown -c cancels it), or sleeps or hibernates through systemd.

Limits on Linux

  • Links can be dropped on the drop target, not on the main window.
  • Choosing the network for several networks at once needs Linux 5.7 or later.
  • Sign-in to proxies and sites with NTLM uses the name and password in the address; Kerberos isn't supported.
  • "Look up files in browser cache" reads Firefox's cache only.
