Welcome to New Download Manager

NDM is a free, open-source download manager for Windows. It splits every file into parts fetched side by side, resumes broken downloads, takes over downloads from your browser, saves video streams and can explore whole web sites.

  • Starting downloads From the browser, Add URL, the clipboard, drag and drop, batches and the command line.
  • The main window Toolbar, categories, the download list and the notification area icon.
  • How NDM downloads a file Parallel connections, safe resuming and speed limits.
  • Video and audio streams HLS and DASH video, live recordings and older stream types.
  • Scheduler and queues Download at night, keep files in sync and set data limits.
  • Site Grabber Collect every picture, document or page of a web site.
  • Options Every setting, page by page.
  • Customizing NDM Toolbar, columns, language, fonts and translations.
  • Updates Staying on the latest version.

New to NDM? Install the browser extension from the NDM folder in the Start menu, then click any download link: NDM takes it from there.

NDM's source code, releases and issue tracker live on GitHub.
