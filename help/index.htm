New Download Manager

NDM is a free, open-source download manager for Windows and Linux. It downloads each file over several connections at once, resumes interrupted downloads, takes over downloads from your browser, saves video streams and downloads the files of a web site.

Topics

  • Starting downloads – from the browser, Add URL, the clipboard, drag and drop, batches and the command line.
  • The main window – the toolbar, categories, the download list and the notification area icon.
  • How NDM downloads a file – connections, resuming, speed limits and several networks.
  • Video and audio streams – HLS and DASH video, live recordings and mms, rtmp and rtsp.
  • Scheduler and queues – queues, start and stop times, synchronization and download limits.
  • Site Grabber – downloading the pictures, documents or pages of a web site.
  • Options – each page of the Options window.
  • Customizing NDM – the toolbar, columns, language, font and translations.
  • NDM on Linux – the AppImage, the tray, the browser extension and desktop settings.
  • Updates – checking for and installing a new version.

Downloads from your browser only reach NDM once its extension is installed (see From your browser).

The source code, releases and issue tracker are on GitHub.
