Options

Tasks → Options holds every setting, grouped in pages. Here is what each page is for.

General

Start NDM with Windows, watch the clipboard for download addresses, and choose the browsers NDM takes downloads from.

  • Keys sets the keys that force or prevent a download with NDM.
  • Customize menu items chooses the entries in the browser's right-click menu.
  • Edit sets up the download panel shown over web players.

Use advanced browser integration also catches downloads from other programs: while it is ticked, Windows sends plain http traffic through NDM, which takes the files it would take from a browser. Secure (https) traffic isn't affected, and your own proxy setting is put back when you untick it or exit NDM.

File types

The file extensions NDM takes over from browsers, and the sites and addresses it never takes downloads from.

Save to

The folder of each category, the temporary folder for unfinished parts, and whether a file gets the date the server gives it.

Downloads

Which windows appear when a download starts and completes, what to do with a link that is already in the list, which virus checker runs on finished files, and how the progress window looks.

Connection

The number of connections per download, lower limits for single servers, and download limits.

Proxy / Socks

No proxy, Windows' proxy settings, an automatic configuration script, or your own HTTP, HTTPS, FTP and SOCKS 4/5 proxies (Advanced), plus the addresses that skip the proxy. Use proxy/socks from a browser's request retries a failed browser download through the browser's own proxy.

Site logins

User names and passwords NDM sends to sites that ask for them.

Dial Up / VPN

Choose a Windows dial-up or VPN connection that NDM connects before downloading when you are offline, with its user name, password and how often to redial.

Sounds

Sounds for completed and failed downloads, and for queues starting and stopping.
