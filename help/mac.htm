NDM on macOS

On a Mac, NDM is one app for Apple Silicon and Intel processors, for macOS 11 or later. This page covers what differs from Windows.

Installing

  1. Download NDM-<version>-macOS.dmg from the release page and open it.
  2. Drag NDM onto Applications.
  3. The first time, right-click (or Control-click) NDM in Applications and choose Open, then Open again. NDM isn't notarized by Apple, so a plain double-click is refused once. After that it starts normally. (In Terminal, xattr -dr com.apple.quarantine /Applications/NDM.app does the same.)

Check for updates downloads the new disk image and replaces the app in place, then starts it again.

The menu bar icon

While NDM runs, its icon sits in the menu bar, where Windows has the notification area icon: Open, the main queue, the Speed Limiter and Exit. Closing the window keeps NDM running there.

The browser extension

NDM keeps a copy of its browser extension in ~/Library/Application Support/NewDownloadManager/extension, which stays in place when NDM is updated. Load that folder (see From your browser); Options → General → Reintegrate All shows the steps for each browser. NDM registers itself with Chrome, Edge, Brave, Vivaldi, Opera, Chromium and Firefox.

Where NDM keeps its files

Settings and the download list are in ~/Library/Application Support/NewDownloadManager, with the toolbars and category icons folders.

System settings

  • Use system settings on the Proxy / Socks page reads the proxy and the auto-configuration script set in System Settings → Network.
  • The Dial Up / VPN page lists the VPN connections set up in System Settings; NDM connects one before downloading.
  • Launch New Download Manager on startup starts NDM when you log in.
  • Sounds play through the system; Turn off computer when done asks the open programs to quit and shuts down, or puts the Mac to sleep.
  • Sites asking for Negotiate sign in with your Kerberos ticket.

Dropping links

Drag a link from the browser onto NDM's window, or onto the drop target: Tasks → Show drop target puts NDM's icon in a small window that floats over other windows on every desktop (Space). Drag it to move it, double-click it to open NDM, right-click it to close it. File and program icons in NDM's lists are the Finder's.

Limits on macOS

  • Advanced browser integration (system-wide capture) is Windows-only.
  • "Look up files in browser cache" reads Firefox's cache only.
