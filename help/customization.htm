Customizing NDM

Make NDM look and read the way you like.

Toolbar

Right-click the toolbar to add, remove and reorder buttons and separators, switch between large and small buttons, and pick the Modern or Classic style. Look for new toolbars opens NDM's release page, where new styles appear.

Columns

Right-click the column headers of the download list to choose which columns are shown, their order and their width.

View menu

  • Language changes the language of menus and windows.
  • Font changes the font of the download list.
  • Dark Mode support follows Windows' dark app mode.
  • NDM tray icon shows the notification area icon in 3D style, Classic style, or not at all.

Translating NDM

Languages\ndm_en.lng holds every text NDM shows. To add a language:

  • Copy it to ndm_xx.lng, where xx is your language's code.
  • Change the first line to your language's ID and name.
  • Translate the text after each "=".

NDM lists the new file under View → Language as soon as it finds it. Pull requests with translations are very welcome on GitHub.
