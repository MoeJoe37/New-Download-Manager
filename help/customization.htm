Customizing NDM

The look, the toolbar, the sizes of the main window's parts, the download list's columns, the language, the list font and the tray icon can all be changed.

Styles

View → Toolbar (or a right click on the toolbar) offers three looks:

  • Modern style: chevrons in the category tree and grid lines in the download list.
  • Classic style: +/- boxes in the tree and the 3D look of older Windows programs.
  • NDM Style: NDM's own design for every window: rounded controls, one accent colour, line icons, a sidebar without tree lines, progress bars in the list and a status bar with the number of downloads and the total speed. With dark mode on, every window turns dark.

Toolbar

Right-click the toolbar to add, remove and reorder buttons and separators (Customize...), switch between large and small buttons, and choose the style.

A custom toolbar puts your own pictures on the buttons: a folder of PNG files, one per button, in NDM's toolbars folder (Open toolbars folder creates and opens it). Every such folder is listed in the menu by its name; Built-in toolbar goes back to NDM's icons. Look for new toolbars opens the guide to making and installing them on NDM's GitHub page.

Custom scale

View → Custom scale... makes parts of the main window larger or smaller, from 50% to 200%: the Toolbar (buttons, pictures and labels), the Categories pane (rows, icons and names) and the Text size of the menus, the download list and the status bar. Changes show at once; Cancel puts the sizes back, Reset returns to 100%.

Columns

Right-click the column headers of the download list to choose the columns and their order. Drag a header's edge to change its width.

View menu

  • Language changes the language of menus and windows.
  • Font changes the font of the download list; Reset to default Font undoes it.
  • Dark Mode support follows the system's dark mode: Windows' dark app mode, or the desktop's dark style on Linux.
  • NDM tray icon shows the notification area icon in 3D style, in Classic style, or not at all.

Translating NDM

Languages/ndm_en.lng holds every text NDM shows. To add a language:

  1. Copy the file to ndm_xx.lng, where xx is your language's code.
  2. Change the first line to your language's ID and name.
  3. Translate the text after each "=".

NDM lists the new file under View → Language the next time it starts. Translations are welcome as pull requests on GitHub.
