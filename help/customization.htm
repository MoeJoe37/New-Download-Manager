Customizing NDM

The look, the toolbar, the sizes of the main window's parts, the download list's columns, the language, the list font and the tray icon can all be changed.

Styles

View → Themes offers two built-in looks and any custom themes you install:

  • Modern style: chevrons in the category tree and grid lines in the download list.
  • NDM Style: NDM's own design for every window: rounded controls, one accent colour, line icons, a sidebar without tree lines, progress bars in the list and a status bar with the number of downloads and the total speed. With dark mode on, every window turns dark.

Toolbar

Right-click the toolbar to add, remove and reorder buttons and separators (Customize...), and choose a picture set. Choose the style under View → Themes. Use View → Custom scale... to change the toolbar size.

A custom toolbar puts your own pictures on the buttons: a folder of PNG files, one per button, in NDM's toolbars folder (Open toolbars folder creates and opens it). Every such folder is listed in the menu by its name; Built-in toolbar goes back to NDM's icons. Help → Look for new toolbars opens the guide to making and installing them on NDM's GitHub page.

Category icons

View → Category icons puts your own pictures in the categories pane: a set is a folder of PNG files, one per item (all-downloads.png, unfinished.png, finished.png, video.png, queues.png...), in NDM's category icons folder (Open category icons folder creates and opens it). Each set is listed in the menu by its name; Built-in icons goes back to NDM's own. Items without a picture keep NDM's icon. Help → Look for new category icons opens the guide with every file name.

Custom scale

View → Custom scale... makes parts of the main window larger or smaller, from 50% to 200%: the Toolbar (buttons, pictures and labels), the Categories pane (rows, icons and names) and the Text size of the menus, the download list and the status bar. Changes show at once; Cancel puts the sizes back, Reset returns to 100%.

Columns

Right-click the column headers of the download list to choose the columns and their order. Drag a header's edge to change its width.

View menu

  • Language changes the language of menus and windows: English, Spanish, French, Arabic, or a language file you added. Arabic is written right to left, so every window is mirrored.
  • Font changes the font of the download list; Reset to default Font undoes it.
  • Dark Mode support follows the system's dark mode: Windows' dark app mode, the desktop's dark style on Linux, or macOS's dark appearance.
  • NDM tray icon offers Default (the flat NDM picture), Choose icon..., Custom icon after importing, or Don't show. App and tray icons are independent.
  • NDM icon changes the app's running window, title bar and taskbar icon, About picture, help logo, and drop target. Default restores the original app icon.

Custom app and tray icons

Choose View → NDM tray icon → Choose icon... or View → NDM icon → Choose icon..., then select a PNG, JPEG, WebP, BMP, GIF, ICO or self-contained SVG. NDM detects the image contents even if the extension is wrong, keeps transparency and proportions, and converts it to a square PNG. It also creates a Windows ICO with pictures from 16 to 256 pixels. Animated files use their first frame. SVGs must embed their pictures and must not refer to outside files or websites. Maximum file size is 16 MiB.

NDM keeps converted copies beside its settings, in the icons folder. Choices survive restarting, and the original image can be moved or deleted. A damaged or unsupported image shows an error and keeps the current selection. Default restores the built-in picture. The old 3D tray choice now uses Default.

The app icon updates running windows and their taskbar/title icons immediately. NDM also updates shortcuts belonging to your Windows account, a per-user Linux launcher and Wayland dock icon, and the macOS Dock and Finder app-bundle icon. Finder needs write access to the app bundle. Windows Explorer's image for the executable itself is embedded at build time; changing icons does not rewrite the executable. If a pinned launcher keeps an old cached picture, unpin and pin it again.

Don't show hides the tray icon. Without a tray icon, closing minimizes NDM while downloads run, or exits when idle. Linux tray availability depends on the desktop.

Installing and using themes

View → Themes holds Modern style, NDM Style, and installed custom themes. Toolbar picture sets remain under View → Toolbar. A theme is a JSON file and optional pictures/fonts, with no executable scripts.

  1. Unzip a theme, keeping theme.json and its asset folders together.
  2. Choose Install theme... and select theme.json. NDM validates it, copies its referenced assets to its own themes folder, and selects it. You no longer need the source folder.
  3. Use Open themes folder to find the installed copy. You can also put complete theme folders here yourself; reopen Themes to list them.
  4. Edit the installed theme.json and choose Reload theme. Images and fonts reload too. An invalid edit shows the error and leaves the previous working theme active.
  5. Select Modern style or NDM Style to restore a built-in appearance. Select another theme before deleting an installed theme folder. A missing or invalid theme at startup falls back to its built-in base.

The themes folder is beside state.json: %APPDATA%\NewDownloadManager\themes on Windows; $XDG_CONFIG_HOME/NewDownloadManager/themes (or ~/.config/NewDownloadManager/themes) on Linux; ~/Library/Application Support/NewDownloadManager/themes on macOS.

Creating a theme

Choose Create theme.... NDM opens a new My-theme folder with a working theme.json and two reference files: style-reference-light.json and style-reference-dark.json. The reference files show all current standard-control field names and value shapes; they are not applied automatically. Edit theme.json, select its name in Themes, then Reload theme after edits. The repository includes examples/themes/Aurora/theme.json.

{
  "version": 1,
  "name": "My violet theme",
  "base": "ndm",
  "common": {
    "palette": { "accent": "#8465E8" }
  }
}

Version must be 1. Name is the menu label. Base is ndm or modern (ndm if omitted). All other fields are optional. NDM starts with the built-in base, applies common, then applies light or dark according to Dark Mode support and the operating system. Unspecified properties keep their base values. Remove a property to inherit it again. Your saved toolbar layout, scaling, list font, picture sets and download settings stay available when you switch back to a built-in theme.

Common, light and dark may each contain palette, metrics, style and regions.

  • Palette: bg (background), surface (fields and surfaces), raised, border, text, muted, accent, accent_hot, accent_soft, on_accent, danger and success. Colors are #RRGGBB or #RRGGBBAA. NDM's painted controls use these too. toolbar.add-url and the other toolbar button file names can tint NDM Style's line icons.
  • Metrics: control_radius and card_radius; menu_font, toolbar_font, categories_font, list_font and status_font (6–96 points); toolbar_icon_size (0.25–4 multiplier); list_row_height (at least the text height). Custom scale is applied to the relevant main-window fonts and toolbar size. Use the NDM base for rounded painted controls.
  • Regions: app, menu, toolbar, sidebar, list, status, dialog, grabber, help and popup. Status is available in the NDM base. Each region can set fill, image, image_mode, image_opacity, border, border_width, corner_radius, margin and its own partial style.
"regions": {
  "toolbar": {
    "fill": "#203044",
    "image": "images/toolbar.png",
    "image_mode": "cover",
    "image_opacity": 0.45,
    "border": "#526680",
    "border_width": 1,
    "corner_radius": 8,
    "margin": [8, 8, 4, 4]
  }
}

This regions object belongs inside common, light or dark. Put toolbar.png in the theme's images folder. Image modes are cover (fill and crop), contain (fit), stretch, and tile. Opacity is 0–1; margin is [left, right, top, bottom]. Regions have separate backgrounds: set each region you want to change. Popup margins use style.spacing.menu_margin. A popup region border decorates its content; its outer frame uses the standard visual style. Native title bars, file pickers and tray menus follow the operating system.

Theme controls, fonts and pictures

Style is a partial standard-control style. Look in the generated reference files for all fields: visuals, widget states, selection, strokes, shadows, spacing, scrollbar settings and text_styles. Copy only properties you want to override, leaving the rest inherited. For example, put this inside common:

"style": {
  "spacing": { "button_padding": { "x": 12, "y": 4 } },
  "text_styles": { "Body": { "size": 12 } },
  "visuals": {
    "selection": { "bg_fill": "#6845AA" },
    "widgets": { "hovered": {
      "bg_fill": "#DACDFA", "weak_bg_fill": "#DACDFA"
    } }
  }
}

Unknown fields and invalid values are rejected. App-specific painted controls use palette and metrics; standard-control style fields apply to egui controls. A region's own style is applied after the global style.

A top-level fonts object maps family names to TTF/OTF files, for example "fonts": { "proportional": "fonts/MyFont.ttf" }. Special families are proportional, monospace, segoe and list. Other names create a named family, used as "family": { "Name": "MyFamily" } in a text style. Keep the real font files in the theme folder.

Top-level toolbar_icons and category_icons point to PNG folders, for example "toolbar_icons": "toolbar", "category_icons": "categories". Use the file names in the custom toolbar and category-icon guides. Only included pictures override the user's picture sets; missing pictures keep their normal fallbacks. Toolbar -hot and -disabled variants are supported. Selecting another theme restores the underlying choices.

All assets must be relative paths inside the theme folder, including after resolving symlinks. To share a theme, zip theme.json with its referenced asset folders. The recipient unzips it and uses Install theme.... Do not include state.json or downloads. The README's Custom themes section has complete examples and field tables.

Translating NDM

Languages/ndm_en.lng holds every text NDM shows. To add a language:

  1. Copy the file to ndm_xx.lng, where xx is your language's code.
  2. Change the first line to your language's ID and name.
  3. Translate the text after each "=". Keep %s, %d and \n, in the same order: NDM puts values there.

A text you leave out shows in English, and a translation longer than the English is drawn a little smaller to fit. The line starting with "%b %d" is the date format (for example %d/%m/%Y for day/month/year). Files named ndm_ar, ndm_fa, ndm_he or ndm_iw are right to left: NDM mirrors the windows and lays the text out itself.

NDM lists the new file under View → Language the next time it starts. Translations are welcome as pull requests on GitHub.
