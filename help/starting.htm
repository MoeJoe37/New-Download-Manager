Starting downloads

There are several ways to hand a file to NDM. Most of the time you won't think about it at all: click a link in your browser and NDM asks where to save it.

From your browser

The NDM extension works in Chrome, Edge, Brave, Opera, Vivaldi and Firefox. When you click a download link, the extension passes it to NDM instead of letting the browser save it, and NDM opens its Download File Info window. If NDM isn't running yet, the extension starts it quietly in the notification area.

  • Only the file types listed in Options → File types are taken over. Sites and addresses on the exception lists stay with the browser.
  • Hold Del while clicking to let the browser download a file, or Ins to make NDM take it whatever its type. You can change these keys in Options → General → Keys.
  • Right-click a link and choose Download with New Download Manager, or right-click a page and choose Download all links with New Download Manager to pick files from every link on it.
  • Video and audio players get a small download panel listing the streams the page plays. See Video and audio streams.

Add URL

Click Add URL on the toolbar and paste an address: http, https, ftp, or an mms, rtmp or rtsp stream. Tick Use authorization if the server needs a user name and password.

Copied addresses

With Automatically start downloading of URLs placed to clipboard ticked in Options → General, copying the address of a file of a listed type offers to download it straight away.

Drag and drop

Drag a link from any browser onto the main window, or onto the floating drop target (Tasks → Show drop target), which stays on top of other windows.

Batch downloads

Tasks → Add batch download fetches a series of files whose addresses differ only by a number or a letter. Put a * where the address changes and choose the range:

http://www.example.com/photos/img*.jpg   (from 001 to 120)

Importing a list

Tasks → Import adds every address from a text file, or from an export file (.ef2) saved by NDM or another download manager. Tasks → Export saves your own list the same way.

Command line

ndm.exe [/d URL] [/p folder] [/f file name] [/n] [/a] [/q] [/s]
  • /d URL downloads the address; /p saves it in this folder and /f under this name.
  • /n starts without asking any questions; /a only adds the file to the main queue.
  • /q closes NDM once the download is done; /s starts the main queue.

If NDM is already running, the running copy takes the command, so scripts can call ndm.exe as often as they like.

The Download File Info window

Before a download starts, NDM shows its address, the category it picked and where the file will be saved. Change the category or the path if you like, then click Start Download, or Download Later to put it in a queue for the scheduler.
