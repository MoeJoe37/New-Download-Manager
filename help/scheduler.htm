Scheduler and queues

Queues download their files a few at a time, in order, whenever you tell them to: overnight, on certain days, or as soon as NDM starts.

Queues

Download Later puts a file in a queue; right-click downloads to move them between queues. The Main Download Queue always exists, and you can create more with New queue in the Scheduler.

Schedule

For each queue, choose:

  • when it starts: once, or every day or on chosen days at a set time;
  • when it stops;
  • how many files it downloads at once and how often a failed file is retried.

A queue can also start whenever NDM starts.

When a queue is done

Once a queue has finished, NDM can open a file, hang up a dial-up or VPN connection, exit, or shut down, sleep or hibernate the computer.

Synchronization queue

Files in a synchronization queue stay in it after they finish. Each time the queue runs, NDM asks the server whether each file has changed and downloads only the changed ones. Set Start again every to check them regularly.

Download limits

Limit how much NDM may download in a period, for example 200 MB every 5 hours. Downloading pauses when the limit is reached and carries on in the next period.

Download limits are handy on metered connections and mobile hotspots.
