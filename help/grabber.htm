Site Grabber

The Site Grabber explores a web site from a start page, follows its links and downloads the files you want: every picture of a gallery, every PDF on a site, or a whole site to read offline.

The wizard

  • Step 1. Choose a template, for example All images from a web site or Complete web site, and enter the start page. If the site needs a login, enter it, or tick the manual login page to log in through your browser first.
  • Step 2. Choose where files are saved: all in one folder, by category, or keeping the site's own folder structure.
  • Step 3. Choose how deep NDM explores: how many levels of links from the start page, whether to stay on the same site, and which paths to explore or skip.
  • Step 4. Choose which files to download: file type masks, sizes, and whether pages are converted for offline browsing.

The results window

While exploring, the results window lists every page and file found, by page, site or folder, with a thumbnail view for pictures. Tick the files you want and download them, or add them to the main list.

Projects and schedules

Save your settings as a project to run them again later. A project can be scheduled to run at a set time, or to fetch only what is new on the site at regular intervals.

Grabber settings

Set how pages are explored, how many files are downloaded at once, and whether link texts become file descriptions.

Please respect the sites you grab: keep the number of connections modest and follow their terms of use.
